## 系統前置狀態拆解

| 部件 | 資料型別 | 建置方式 | 內部子結構 | Given 句型 |
|------|---------|---------|-----------|-----------|
| 擁有者憑證 | OwnerCredential | Data Table | 無（password 明文由 step 雜湊後寫入） | `Given 擁有者憑證為：` |
| 擁有者登入狀態 | JWT（不落庫） | 呼叫登入 API | 無 | `Given 擁有者已登入` |
| 過期 JWT | JWT（不落庫） | 以 25 小時前簽發時間產生 | 無 | `Given 擁有者持有已過期的 JWT` |
| Satellite 集合 | Satellite[] | Data Table | 無 | `Given 系統中有以下衛星：` |
| SubSatellite 集合 | SubSatellite[] | Data Table（以 `$衛星.id` 指父層） | 無 | `Given 系統中有以下子衛星：` |
| Paragraph 集合 | Paragraph[] | Data Table（以 `$子衛星.id` 指父層） | 無 | `Given 系統中有以下段落：` |

> 葉子部件 6 個 → Given 句型 6 個。實體在後續步驟以 `$<name>.id` 引用（例：`$天文.id`）。

## 行為分類與句型骨架

### Creation（新增衛星 / 新增子衛星 / 新增段落）

- When：`When 擁有者新增<實體>：`（接 Data Table；有父層時含 `parent_id` 欄）
- Then（成功）：`Then 操作成功` + `And 系統中應有以下<實體>：`（States Verify）
- Then（失敗）：`Then 操作失敗，狀態碼為 <status>，錯誤代碼為 "<code>"`

### Mutation（編輯 × 3、刪除 × 3、登入）

- When：`When 擁有者編輯<實體>：` / `When 擁有者刪除<實體> "<id>"` / `When 以密碼 "<password>" 登入後台`
- Then（成功）：`Then 操作成功` + States Verify（編輯：欄位值；刪除：`系統中不應有<實體> "<name>"`；登入：回應含 token、failed_attempts 歸零）
- Then（失敗）：同 Creation

### Query（列出衛星 / 列出子衛星 / 列出段落）

- When：`When 查詢<清單>`（未登入，公開）
- Then（成功）：`Then 操作成功` + `And 查詢結果應依序為：`（readmodel-then，順序即排序規則）
- Then（失敗）：同 Creation（僅 404）

## 共用契約

### Postcondition 模式

| 模式 | 適用 | 驗證方式 |
|------|------|---------|
| P1 新增後存在 | Creation × 3 | States Verify：DB 中有該筆，欄位值相符 |
| P2 編輯後欄位更新 | 編輯 × 3 | States Verify：DB 中欄位值為新值（Paragraph 另驗 updated_at 晚於 created_at） |
| P3 刪除後不存在 | 刪除 × 3 | States Verify：DB 中無該筆 |
| P4 清單內容與排序 | Query × 3 | readmodel-then：回應陣列順序與內容 |
| P5 空清單 | Query × 3 | readmodel-then：回應為 `[]` |

### Violation 模式

| 前置條件 | 狀態碼 | 錯誤代碼 | 適用操作 |
|---------|-------|---------|---------|
| 未帶 JWT / JWT 無效 / 過期 | 401 | `UNAUTHORIZED` | 所有 Creation、編輯、刪除 |
| 必填欄位為空 | 400 | `REQUIRED_FIELD_EMPTY` | Creation × 3、編輯 × 3、登入（password） |
| 欄位超過長度上限 | 400 | `FIELD_TOO_LONG` | 衛星／子衛星 name、段落 title |
| 目標或父層不存在 | 404 | `NOT_FOUND` | 編輯 × 3、刪除 × 3、新增子衛星／段落、列出子衛星／段落 |
| 名稱重複 | 409 | `NAME_DUPLICATED` | 新增／編輯 衛星、子衛星 |
| 尚有子資料 | 409 | `HAS_CHILDREN` | 刪除衛星、刪除子衛星 |
| 密碼錯誤 | 401 | `INVALID_PASSWORD` | 登入 |
| 登入鎖定中 | 429 | `LOGIN_LOCKED` | 登入 |

> 錯誤回應統一為 `{ "code": "<錯誤代碼>", "message": "<人類可讀訊息>" }`；BDD 只驗 `code`，`message` 文字由 Phase 04 定義。

## 不屬於 web-backend boundary 的 Rule

以下 Rule 描述 3D 場景或 UI 行為，後端 E2E 無法驗證。Phase 03 **不填 Examples**，在 Rule 旁標 `# @frontend：Phase 06 驗證`，由 Phase 06（Frontend Build / Chrome Test）覆蓋：

| Feature | Rule |
|---------|------|
| 瀏覽3D宇宙 | 載入 3D 宇宙場景、自動慢速旋轉、場景顯示所有 Satellite、WebGL fallback |
| 探索衛星 | 相機飛入近景、SubSatellite 環繞顯示 |
| 查看段落 | Modal 呈現 Paragraph 清單、無 Paragraph 時 Modal 空狀態 |
| 刪除衛星／子衛星／段落 | 刪除前顯示確認對話框 |
| 進入後台 | 只有擁有者可進入後台（UI 面向）；「可看到後台管理介面」中的 UI 部分 |

## 變異點索引

| 實體 | 特有行為 | 需要的專屬句型類別 |
|------|---------|------------------|
| OwnerCredential | 連續錯誤計數、15 分鐘鎖定、JWT 24 小時效期 | Given 憑證狀態、Given 過期 JWT、Then 回應含 token |
| Satellite / SubSatellite | 名稱唯一（全域 vs 同父層）、刪除護欄 | Then 失敗 `NAME_DUPLICATED` / `HAS_CHILDREN` |
| Paragraph | summary 選填、rich text content、updated_at | Then 驗 updated_at |
| Universe（讀取視圖） | 公開、排序方向不同（段落新→舊） | Then 查詢結果依序 |
