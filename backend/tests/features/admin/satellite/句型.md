# satellite 句型模型

## 實體概述

- **性質**: Aggregate — `satellites`
- **攜帶狀態**: id, name（≤50）, created_at
- **Invariant 清單**:
  - I1：name 非空、長度 ≤ 50
  - I2：name 全域唯一（不與「其他」Satellite 相同；改成自己現有名稱不算重複）
  - I3：刪除時連帶刪除底下所有 SubSatellite 及其 Paragraph（`delete: cascade`）

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 新增衛星 | Creation | name | name | 401 `UNAUTHORIZED`、400 `REQUIRED_FIELD_EMPTY`、400 `FIELD_TOO_LONG`、409 `NAME_DUPLICATED` |
| 編輯衛星 | Mutation | satellite_id, name | id, name | 401 `UNAUTHORIZED`、404 `NOT_FOUND`、400 `REQUIRED_FIELD_EMPTY`、400 `FIELD_TOO_LONG`、409 `NAME_DUPLICATED` |
| 刪除衛星 | Mutation（刪除，cascade） | satellite_id（句中） | — | 401 `UNAUTHORIZED`、404 `NOT_FOUND` |

## 測試資料

| 代稱 | 值 |
|------|----|
| 50 字名稱 | 「星」× 50 |
| 51 字名稱 | 「星」× 51 |
| 不存在的 id | `99999` |

## 測試分析

### 新增衛星

Background：G1；G3 = `天文`（2026-01-01 00:00）

**等價類劃分**: name 分三類——合法新名稱／空字串／與既有名稱重複。
**邊界值分析**: 長度 50（可以）vs 51（拒絕）。
**狀態轉移**: 不適用（Creation 沒有前置狀態轉移）。
**組合覆蓋**: JWT 三種狀態 × 合法輸入 → 都回 401。
**錯誤推測**: 名稱前後有空白、大小寫視為同名——Rule 未確認，不納入。

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 未帶 JWT | G2 未帶 | name=音樂 | 失敗(401 UNAUTHORIZED) | 組合 |
| 2 | JWT 已過期 | G2 已過期 | name=音樂 | 失敗(401 UNAUTHORIZED) | 組合 |
| 3 | JWT 無效 | G2 無效 | name=音樂 | 失敗(401 UNAUTHORIZED) | 組合 |
| 4 | 名稱為空 | （無） | name="" | 失敗(400 REQUIRED_FIELD_EMPTY) | 等價類 |
| 5 | 名稱 51 字 | （無） | name=星×51 | 失敗(400 FIELD_TOO_LONG) | 邊界值 |
| 6 | 名稱 50 字可建立 | （無） | name=星×50 | 成功、系統中有該衛星 | 邊界值 |
| 7 | 名稱重複 | （無） | name=天文 | 失敗(409 NAME_DUPLICATED) | 等價類 / 錯誤推測 |
| 8 | 新增成功出現在清單 | （無） | name=音樂 | 成功、系統中有 天文、音樂 | 等價類 |

### 編輯衛星

Background：G1；G3 = `天文`（2026-01-01）、`程式設計`（2026-01-02）

**等價類劃分**: 目標存在／不存在；name 合法／空／與其他衛星重複／與自己現有名稱相同。
**邊界值分析**: 長度 50 vs 51。
**狀態轉移**: 改名前後：同一個 id 的 name 由「天文」變成「天文學」。
**組合覆蓋**: JWT 三種狀態 → 都回 401。
**錯誤推測**: 改成自己現有的名稱，不應誤判為重複（依 I2）。

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1–3 | JWT 未帶／已過期／無效 | G2 | $天文.id → 天文學 | 失敗(401 UNAUTHORIZED) | 組合 |
| 4 | 目標不存在 | （無） | 99999 → 天文學 | 失敗(404 NOT_FOUND) | 狀態轉移 |
| 5 | 名稱為空 | （無） | $天文.id → "" | 失敗(400 REQUIRED_FIELD_EMPTY) | 等價類 |
| 6 | 名稱 51 字 | （無） | $天文.id → 星×51 | 失敗(400 FIELD_TOO_LONG) | 邊界值 |
| 7 | 名稱 50 字可更新 | （無） | $天文.id → 星×50 | 成功、$天文.id 的 name=星×50 | 邊界值 |
| 8 | 與其他衛星重複 | （無） | $天文.id → 程式設計 | 失敗(409 NAME_DUPLICATED) | 等價類 |
| 9 | 改成自己現有的名稱 | （無） | $天文.id → 天文 | 成功 | 錯誤推測 |
| 10 | 編輯成功資料更新 | （無） | $天文.id → 天文學 | 成功、$天文.id 的 name=天文學 | 狀態轉移 |

### 刪除衛星

Background：G1；G3 = `天文`、`程式設計`；G4 = `星系`（satellite_id=$天文.id）

**等價類劃分**: 目標存在且沒有子衛星／存在且有子衛星（含段落）／不存在。
**邊界值分析**: 子衛星數量 0 vs ≥1——兩者都可刪除；≥1 時下層一併消失。
**狀態轉移**: 刪除後，該衛星及其所有子衛星、段落從系統中消失。
**組合覆蓋**: JWT 三種狀態 → 都回 401。
**錯誤推測**: cascade 誤刪其他衛星（程式設計應仍存在）；只刪到子衛星層、段落殘留。

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1–3 | JWT 未帶／已過期／無效 | G2 | $程式設計.id | 失敗(401 UNAUTHORIZED) | 組合 |
| 4 | 目標不存在 | （無） | 99999 | 失敗(404 NOT_FOUND) | 等價類 |
| 5 | 有子衛星時連帶刪除 | G5 = `銀河系簡介`（$星系.id） | $天文.id | 成功、不應有 天文／星系／銀河系簡介、仍有 程式設計 | 邊界值 / 錯誤推測 |
| 6 | 刪除成功後消失 | （無） | $程式設計.id | 成功、系統中不應有 程式設計 | 狀態轉移 |
