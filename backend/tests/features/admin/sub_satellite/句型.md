# sub_satellite 句型模型

## 實體概述

- **性質**: Aggregate — `sub_satellites`
- **攜帶狀態**: id, satellite_id, name（≤50）, created_at
- **Invariant 清單**:
  - I1：name 非空、長度 ≤ 50
  - I2：(satellite_id, name) 唯一——同一 Satellite 內不可同名；不同 Satellite 底下可同名；改成自己現有名稱不算重複
  - I3：satellite_id 必須指向存在的 Satellite
  - I4：刪除時連帶刪除底下所有 Paragraph（`delete: cascade`）
  - I5：編輯只改 name，不可搬到其他 Satellite（Rule 未提及搬移）

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 新增子衛星 | Creation | satellite_id, name | satellite_id, name | 401 `UNAUTHORIZED`、404 `NOT_FOUND`、400 `REQUIRED_FIELD_EMPTY`、400 `FIELD_TOO_LONG`、409 `NAME_DUPLICATED` |
| 編輯子衛星 | Mutation | sub_satellite_id, name | id, satellite_id, name | 401 `UNAUTHORIZED`、404 `NOT_FOUND`、400 `REQUIRED_FIELD_EMPTY`、400 `FIELD_TOO_LONG`、409 `NAME_DUPLICATED` |
| 刪除子衛星 | Mutation（刪除，cascade） | sub_satellite_id（句中） | — | 401 `UNAUTHORIZED`、404 `NOT_FOUND` |

| 代稱 | 值 |

## 測試分析

### 新增子衛星

Background：G1；G3 = `天文`、`程式設計`；G4 = `星系`（$天文.id）

**等價類劃分**: 父層存在／不存在；name 合法／空／同父層重複／不同父層同名。
**邊界值分析**: 長度 50 vs 51。
**狀態轉移**: 不適用（Creation）。
**組合覆蓋**: JWT 三種狀態 → 都回 401；name × 父層：同名在同父層（拒絕）vs 不同父層（可建立）。
**錯誤推測**: 誤把唯一性做成全域唯一（#9 防範）；名稱前後空白、大小寫——Rule 未確認，不納入。

|---|---------|-------------|-------------|---------|---------|
| 1–3 | JWT 未帶／已過期／無效 | G2 | $天文.id, 行星 | 失敗(401 UNAUTHORIZED) | 組合 |

### 編輯子衛星

Background：G1；G3 = `天文`、`程式設計`；G4 = `星系`（$天文.id）、`行星`（$天文.id）、`演算法`（$程式設計.id）

**等價類劃分**: 目標存在／不存在；name 合法／空／同父層重複／與其他衛星底下的子衛星同名／與自己現有名稱相同。
**邊界值分析**: 長度 50 vs 51。
**狀態轉移**: 同一個 id 的 name 由「星系」變成「星雲」，satellite_id 不變。
**組合覆蓋**: JWT 三種狀態 → 都回 401。
**錯誤推測**: 改成自己現有的名稱不應誤判為重複；和其他衛星底下的子衛星同名不應被拒絕。

|---|---------|-------------|-------------|---------|---------|
| 1–3 | JWT 未帶／已過期／無效 | G2 | $星系.id → 星雲 | 失敗(401 UNAUTHORIZED) | 組合 |

| 5 | 名稱為空 | （無） | $星系.id → "" | 失敗(400 REQUIRED_FIELD_EMPTY) | 等價類 |
| 6 | 名稱 51 字 | （無） | $星系.id → 星×51 | 失敗(400 FIELD_TOO_LONG) | 邊界值 |
| 7 | 名稱 50 字可更新 | （無） | $星系.id → 星×50 | 成功、$星系.id 的 name=星×50 | 邊界值 |
| 8 | 同衛星內重複 | （無） | $星系.id → 行星 | 失敗(409 NAME_DUPLICATED) | 等價類 |
| 9 | 與其他衛星底下的子衛星同名 | （無） | $星系.id → 演算法 | 成功 | 組合 / 錯誤推測 |

### 刪除子衛星

Background：G1；G3 = `天文`；G4 = `星系`、`行星`（皆 $天文.id）；G5 = `銀河系簡介`（$星系.id）

**等價類劃分**: 目標存在且沒有段落／存在且有段落／不存在。
**邊界值分析**: 段落數量 0 vs ≥1——兩者都可刪除；≥1 時段落一併消失。
**狀態轉移**: 刪除後，該子衛星及其所有段落從系統中消失。
**組合覆蓋**: JWT 三種狀態 → 都回 401。
**錯誤推測**: cascade 誤刪同衛星的其他子衛星（行星應仍存在）；段落殘留。

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1–3 | JWT 未帶／已過期／無效 | G2 | $行星.id | 失敗(401 UNAUTHORIZED) | 組合 |
| 4 | 目標不存在 | （無） | 99999 | 失敗(404 NOT_FOUND) | 等價類 |
| 5 | 有段落時連帶刪除 | （無） | $星系.id | 成功、不應有 星系／銀河系簡介、仍有 行星 | 邊界值 / 錯誤推測 |
| 6 | 刪除成功後消失 | （無） | $行星.id | 成功、系統中不應有 行星 | 狀態轉移 |
